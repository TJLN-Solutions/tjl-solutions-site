Crie um site institucional moderno, tecnológico, responsivo e visualmente marcante para uma empresa chamada **BASE4 SYSTEMS**.

## Identidade visual

Utilize como cores principais:

* Azul tecnológico
* Preto
* Tons de azul-escuro
* Branco apenas para textos e contrastes

O visual deve transmitir:

* Tecnologia
* Inovação
* Confiança
* Modernidade
* Profissionalismo

Utilize um estilo futurista e elegante, com fundo predominantemente escuro, detalhes em azul neon, gradientes suaves, transparências, efeitos de vidro — glassmorphism —, sombras discretas e elementos tecnológicos animados.

Não quero um site com aparência de template genérico. O design deve ser diferente, chamativo e profissional.

## Estrutura geral

Crie o site como uma landing page completa, com menu fixo no topo e navegação suave entre as seções.

O menu deve conter:

* Início
* Sobre a BASE4
* Sistemas
* Serviços
* Contato

Inclua no cabeçalho o nome ou logotipo textual:

**BASE4 SYSTEMS**

Adicione um botão destacado:

**Fale com nossa equipe**

Esse botão deve direcionar para a seção de contato.

## Animações e interações

O site deve possuir animações modernas, mas leves.

Inclua:

* Entrada suave dos elementos durante a rolagem
* Animação no título principal
* Efeito de brilho em botões
* Cards que se elevam levemente ao passar o mouse
* Gradientes animados
* Partículas ou linhas digitais discretas no fundo
* Transições suaves entre seções
* Menu com efeito de transparência ao rolar
* Indicador visual da seção ativa
* Rolagem suave
* Botão flutuante do WhatsApp
* Pequenos efeitos de luz acompanhando o cursor em computadores

Não utilize animações exageradas que prejudiquem a velocidade ou a leitura.

Respeite a configuração “prefers-reduced-motion” para usuários que desativam animações no dispositivo.

---

## Responsividade

O site deve funcionar perfeitamente em:

* Celulares
* Tablets
* Notebooks
* Monitores grandes

No celular:

* Transforme o menu em menu hambúrguer
* Mantenha os botões grandes e fáceis de tocar
* Organize os cards em uma coluna
* Garanta que os números de telefone fiquem legíveis
* Evite textos muito pequenos
* Mantenha o botão flutuante do WhatsApp sem cobrir o conteúdo

---

## Requisitos técnicos

Utilize:

* React
* TypeScript
* Tailwind CSS
* Componentes reutilizáveis
* Ícones modernos, como Lucide React
* Animações com Framer Motion ou solução equivalente
* Código organizado e de fácil manutenção

Crie componentes separados para:

* Navbar
* Hero
* Sobre
* Sistemas
* Serviços
* Diferenciais
* Contato
* Localização
* Footer
* Botão flutuante do WhatsApp

Não utilize imagens genéricas de pessoas em escritórios.

Prefira:

* Elementos abstratos
* Ilustrações tecnológicas
* Mockups de sistemas
* Ícones
* Formas geométricas
* Interfaces digitais
* Fundos com circuitos ou conexões

Otimize o site para carregamento rápido.

Utilize HTML semântico e boas práticas de acessibilidade:

* Contraste adequado
* Textos alternativos
* Navegação por teclado
* Labels nos formulários
* Estados de foco visíveis
* Botões com descrições claras

## Orientação final de design

O resultado deve parecer o site de uma empresa de tecnologia moderna e confiável.

Use como referência visual sites de startups SaaS e empresas de desenvolvimento de software, com:

* Fundo preto ou azul muito escuro
* Azul vibrante nos elementos importantes
* Tipografia moderna
* Títulos grandes
* Espaçamento confortável
* Seções bem divididas
* Cards tecnológicos
* Efeitos de luz
* Interface limpa
* Chamadas para ação bem destacadas

O principal objetivo do site é apresentar a BASE4, divulgar os serviços, gerar contatos pelo WhatsApp e criar expectativa para o lançamento do BASE4 Charge.
